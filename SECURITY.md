# Security policy

## Supported versions

Only the `main` branch is supported. There are no tagged releases yet.

## Reporting a vulnerability

Please do not open a public issue for security problems.

1. Preferred: use GitHub's private vulnerability reporting on this repository ("Security" tab, "Report a vulnerability").
2. Alternatively, email **contacto@acabeza.es** with the subject `wordpress-guardian security`.

Include a description, the impact you see and steps to reproduce if you have them. You will get an acknowledgement within 7 days and updates until a fix or a decision is published. Credit is given in the release notes unless you prefer to stay anonymous.

## Scope

In scope: anything in this repository that lets an attacker evade detection, crash the monitor, or exfiltrate the Telegram token. Out of scope: vulnerabilities in WordPress, Telegram, libcurl or the host system.
